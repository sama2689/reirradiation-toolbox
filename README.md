# Reirradiation Image Registration

An open-source Python framework for image registration and cumulative dose assessment in radiotherapy reirradiation.

The framework supports:

- DICOM-RT import and export
- Rigid, B-Spline, and Demons image registration
- Quantitative and qualitative registration evaluation
- RTSTRUCT and RTDOSE propagation
- Cumulative dose and DVH analysis
- BED and EQD2 calculation
- A PySide6 graphical user interface

## Status

This repository contains research software developed as part of an MSc dissertation at the University of Oxford. It is currently a proof-of-concept and has **not been validated or commissioned for clinical use**.

## Requirements

Developed in Python using SimpleITK, pydicom, scikit-image, and PySide6.
